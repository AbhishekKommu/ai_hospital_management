# 🏥 AI Hospital Management System

A beautiful, modern Flask-based hospital management system with an animated background, glassmorphism UI, and full CRUD operations.

## ✨ Features
- 🔐 Authentication (register / login / logout)
- 📊 Live dashboard with stats
- 👥 Patient management (add / list / delete)
- 🩺 Doctor listing
- 📅 Appointment booking
- 🎨 Animated canvas background
- 📱 Responsive design

python -m venv venv
